# 基础教程与可选自动化

## 找到值得读的论文

在 Undermind 或你常用的检索入口提出研究问题，保留题名、DOI/原始论文链接与选择理由。
检索结果只是候选，先核对真实来源和版本，再选出需要入库的清单。工具账户和订阅按各自服务处理；
本仓库安装不会替你开通 Undermind，也不依赖它才能输入 DOI 清单。

## 加入 Zotero

基础方法：安装 [官方 Zotero Connector](https://www.zotero.org/download/)，
在自己已经登录且有访问权限的浏览器中打开论文页面，选择 Zotero 分类并保存。
也可以通过 Zotero 的标识符入口添加书目。保存后检查条目是否重复，标题和作者是否正确，
是否有实际可打开的全文。官方说明见 [Adding Items](https://www.zotero.org/support/adding_items_to_zotero)。

自动化方法：把 README 的安装指令交给本机 Codex，之后给它清单和分类。
skill 复用已有条目并保留原分类；缺 PDF 时继续处理合法来源的全文。
网页快照、登录页、摘要或未附着到父条目的下载文件都不等于全文已入库。

## 交给 Recto 或直接阅读

在 Zotero 先打开并确认全文，再使用你所安装的 Recto 版本提供的 Zotero 导入/关联入口。
保持论文和附件对应，确认导入完成后再启动翻译。核对译文与原文的公式、表格和段落对应。
具体按钮和账户配置应以当前 Recto 文档/界面为准；当前仓库不包含 Recto 自动调用适配器。

不使用 Recto 时可直接阅读 Zotero 中的 PDF。翻译是独立的可选环节，不影响入库模块验收。

## 权限与数据去向

机构权限来自你的浏览器、校园网/VPN 或图书馆登录，不来自 skill。无法获取的全文要报告真实缺口。
入库不要求 Zotero 云同步；现有同步仍可能同步本地修改。检索和翻译服务各有联网与内容处理行为，
不要把“本地入库”理解为整条研究工作流离线。
