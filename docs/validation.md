## 保留的已知限制

本次聚焦安装体验与本机适配，没有把此前审查中的所有增强一起实现：

- 只支持个人文库；群组库拒绝执行。
- 自动 PDF 身份检查仍以标题重合为线索；中文、短标题、扫描件和改题版本需额外人工核验/后续实现。
- 补附件脚本的自动标题过滤仍偏向英文；不能宣传完整中文论文覆盖。
- 仅书目需求可由 agent 单独处理，但当前通用 CLI 没有独立仅书目验收开关。
- 跨站下载依赖 translator、访问权限与网站行为；不存在全站成功保证。
- requirements 是已知基线，不是所有传递依赖的锁文件。安装 agent 记录实际 `pip freeze`，本机变更后重跑测试。
